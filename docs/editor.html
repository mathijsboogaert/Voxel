Voxel map editor

    How it works

    Borders and shop outlines use straight horizontal and vertical lines on the block grid. Click to add corners. Enter, a double-click or a click on the first corner finishes; Esc clears.

    Click a shop to give it an icon and products. Export each file when done, put it in docs/ and push.
